## 2. 証明の記載と読解点検

現行稿には、中心 Veronese 復元、中心正則対による全整数次数の切断飽和性、実際の次数付き商と有限安定化子、中心三次 torsor、点関手の完全交叉成分、Jacobi イデアルの次元境界、残余圏の通常 Artin 形式認識の証明を記載した。

今回の読解点検では、各節の執筆担当とは別の担当による相互点検と、統合時の点検を行った。特に次の範囲を確認した。

| 対象 | 点検した論点 | 残る適用条件・限界 |
|---|---|---|
| 中心復元・次数付きモジュライ | fpqc 持上げ、μ_d、二変数局所化の交わり、Gabriel 商の tail 表示、全次数付き同型、有限安定化子、スカラー重みの相殺 | 低次数中心・相対 PBW の入力を明示。全 O-保存比較には相対 Serre 双対などが別途必要 |
| 点関手 | 非被約基底での分解、M_0 の正規化、8重有限平坦射、中心三次の非零因子条件、次数24・種数37、包絡と Casimir 空間の区別 | 楕円境界・固定点なし等は定理の仮定。特定の中心三次の回復は主張しない |
| Jacobi スキーム | 全係数環での方程式、Plücker 二次空間の次元、整数小行列による一般点証明、頂点完備化の比較、Fermat 例 | n≥8 の非被約性には既存の一般点被約分類を用いる。全 Abel 形式変形とは同定しない |
| 残余圏 | sector 公式の次数、幾何的 KS、滑らかな変形源からの形式認識、tame hull との比較、n=4 の例外、rotation の合同類 | 通常 Artin 基底・特殊ファイバー固定・一次切断の主張。全高次群oidや導来基底へ拡張したとは主張しない |

## 3. 厳密計算の実行

Python 3.12.14、NumPy 2.3.5 で、保存済み証明書の全5個の小行列式を再計算した。証明書生成時の階数探索とは別に、指定された行・列の平方小行列の行列式を直接計算する検証経路を実行し、さらに統合時にも保存済み証明書を読み直して検証した。浮動小数点演算は用いない。

| N=n+2 | 小行列の次数 | 行列式 mod 32003 | 検証 |
|---|---:|---:|---|
| 5 | 5 | 15512 | 一致・非零 |
| 6 | 35 | 14374 | 一致・非零 |
| 7 | 140 | 7973 | 一致・非零 |
| 8 | 420 | 508 | 一致・非零 |
| 9 | 1050 | 13073 | 一致・非零 |

法素数で非零の整数行列式は、特性零でも非零である。この確認により、本文の包含と方程式数の証明を合わせて、一般の滑らかな三次に対するイデアルの一致を得る。選んだ整数係数三次自体の滑らかさを証明する必要はなく、非零小行列の開条件と滑らかな三次の非空開条件の交わりを用いている。

## 5. 再現と保存の区別

再現手順はルートの `README.md` に記した。原稿はルートから `latexmk papers/nc-cubic-n-fold.tex` を実行し、`.latexmkrc` に従って `build/` に出力する。主要な依存は LuaLaTeX、LuaTeX-ja、和文フォント、AMS 等の標準パッケージと Python 3・NumPy である。

保存対象は現在の原稿、研究方針、研究ノート、本検証範囲、文献、再現コード、整数証明書、必要な設定だけとする。入力の全コピー、旧稿、旧bundle、担当者別レポート、外部文献PDF、ビルド中間生成物は含めない。

外部への保存は生成・検証とは別に、GitHub の tree にある全ファイルの blob SHA を手元のソースと照合し、通常の fast-forward による `main` の更新後に、実際の先端 commit と tree を読み直して確認する。保存された版の識別子は Git の履歴と配布時の報告に記す。この文書だけをもって、未実行の外部保存が完了したとは扱わない。
